Структуры в C представляют собой *составной тип данных* и предполагают, что переменная этого типа состоит из *нескольких переменных других типов* (*прозвольных*, что отличает структуры от массивов). Элементы составного типа (переменные) называются *полями*.

Структуры являются аналогом записей в Pascal (см. [[Запись]]). Их не стоит путать с перечислениями enum (см. [[Перечислимый тип]])

## Описание структур

Структуры описываются ключевым словом `struct`, а подход описания похож с перечислимым типом:
* сначала ключевое слово
* необязательное имя (дескриптор/идентификатор/метка), вместе с ключевым словом образующие *имя типа*
* в фигурных скобках -- перечисление полей, каждое представляет собой тип переменной и и ее имя;
* список переменных (необязателен)

То есть:
```c
struct [<имя>] {<список_полей>} [<список_переменных>]
```

## Объявление переменной типа структуры

Сама схема структуры лишь сообщает компилятору, как представлять данные, но не приводит к выделению памяти для хранения этих данных. Чтобы выделить память, необходимо объявить переменную типа структуры.

Пример:
```c
struct student st1;
```

При обработке этой инструкции будет выделена память для всех полей структуры. Эта память объединена в единую конструкцию по общим именем.

Можно и скомбинировать объявление и определение переменной типа структуры в одно действие. Это как раз тот случай, когда становится не нужен дескритор/метка структуры:
```c
struct {
	char title[MAXTITLE];
	char author[MAXAUTHOR];
	float value;
} library;             /* объявлена переменная library */
```
но как только этот шаблон понадобится где-то еще, то метка понадобится, чтобы не указывать его каждый раз.

> [!NOTE] Пространство имен
> В C метки/идентификаторы структур образуют отдельное пространство имен, так что можно использовать такие же идентификаторы для чего-нибудь еще. Однако не рекомендуется, так как например в C++ ситуация противоположная

## Инициализация структуры

Переменные структурного типа можно инициализировать при их описании. Однако подобные конструкции допустимы только при *инициализации* а *не при присваивании*.
При этом используется список инициализаторов, разделенный *запятыми*, заключенный в фигурные скобки.

Пример:
```c
struct book library = {
	"The Pious Pirate and the Devious Damsel",
	"Renee Vivotte",
	1.95
};
```

Присваивать переменные структурного типа друг другу *можно* (в отличие от массивов).
Можно и передавать в функции по значению, как и возвращать из функций (однако лучше так не делать).

### Назначенные инициализаторы

Как и для массивов стандарты C99 и C11 предоставляют *назначенные инициализаторы* для структур (см. также [[Programming/C/Типы данных/Массивы#Назначенные инициализаторы]])

Для структур при этом необходимо указывать операцию точки и имя поля вместо квадратных скобок и индексов. Перечислять поля при этом можно в любом порядке. 

Пример:
```c
struct book surprise = {.value = 10.99};
struct book gift = {.value = 25.99,
					.author = "James Broadfool",
					.title = "Rue for the Toad"};
```

Как и для массивов, если за назначенным иницализатором *следует обычный*, он присвоит значение члену, который следует за указанным в назначенном:
```c
struct book gift = {.value = 18.99,
					.author = "James Broadfool",
					0.25};
```
В итоге поле `value` получит значение `0.25`.

> [!NOTE] Инициализация и продожительность хранения
> Для структур действуют те же правила, что и для других типов переменных:
> 
> * Если инициализируется структура со статической продолжительностью хранения, то значения полей должны быть *константными* выражениями.
> * Если продолжительность хранения является автоматической, то поля *не обязательно* должны быть заданы константными выражениями.
>   
>   См. [[Спецификаторы классов хранения#Различия автоматической и статической продолжительности хранения]]
