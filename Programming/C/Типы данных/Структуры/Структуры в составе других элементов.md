## Массивы структур

Элемент типа данных структуры может в свою очередь быть составной частью иных элементов, таких как массивы или другие структуры.

Объявление массива структур похоже на объявление любого другого массива. Указывается тип данных и количество элементов.

Пример:
```c
struct book library[MAXBKS];
```
где `library` объявляется как массив, содержащий `MAXBKS` элементов типа `struct book`

В таком случае обращение к отдельным элементам (структурам) выполняется аналогично любому другому массиву -- через индексацию:
```c
library[0];
library[1];
...
```

Важно понимать, что имя `library` не является именем структуры -- это имя *массива* (а имя структуры это `book`).

### Обращение к полям структуры как элемента массива

При обращении к полям определенной структуры в массиве *сначала* указываем что за *элемент массива* нам нужен (с применением имени массива и индекса), *затем* как обычно обращаемся к *полям структуры* через `.field`

Пример:
```c
library[0].author; /* значение поля author первого элемента массива */
library[4].title;  /* значение поля title пятого элемента массива */
```

## Вложенные структуры

Очень часто в больших проектах одни структуры являются составной частью какой-нибудь другой структуры для удобной организации работы с данными. В таком случае
вложенная структура просто указывается внутри другой, аналогично тому как это делается для переменных базовых типов.

Пример:
```c
struct names {           /* структура names */
	char first[LEN];
	char last[LEN];
};

struct guy {             /* внешняя   структура */
	struct names handle; /* вложенная структура */
	char favfood[LEN];
	char job[LEN];
	float income;
};
```
При этом файл *должен* включать объявление структуры `names` (напрямую в тексте файла или гораздо чаще -- через включения директивами `#include`).

### Обращение к полям вложенной структуры

Обращение к полям вложенной структуры интуитивно понятным образом:
* сначала обащаемся к нужному полю внешней структуры;
* затем обращаемся к нужному полю вложенной структуры.

Пример:
```c
fellow.handle.first
```
где:
* `fellow`   -- имя переменной типа внешней структуры;
* `.handle` -- операция обращения к полю `handle` элемента `fellow` (типа структуры);
* `.first`   -- операция обращения к полю `first` элемента `handle`.

Для лучшего понимания можно было бы указать скобки, но их не ставят практически никогда:
```c
(fellow.handle).first
```
