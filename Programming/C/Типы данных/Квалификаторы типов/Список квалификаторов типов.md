Переменные в C характеризуются *типом* и *классом хранения*. Начиная со стандарта C90 были добавлены еще 2 свойства:
* постоянство
* изменчивость

Они достигаются с применением *квалификаторов типов*

## Квалификаторы типов

* [[Квалификатор const]] -- пришел из C++, запрещает изменять определенную область памяти
* [[Квалификатор volatile]] -- дает компилятору знать, что переменная или содержимое по адресу могут быть изменены внешними независящими от текущей программы методами
* [[Квалификатор restrict]] -- (C99) дает компилятору знать, что определенный указатель является единственным методом получить доступ к области памяти (первичное средство доступа к объекту данных)
* [[Квалификатор _Atomic]] -- (C11) используется в параллельном программировании

Начиная со стандарта C99 все квалификаторы типов являются *идемпонентными* (один и тот же квалификатор можно указывать более одного раза, избыточные квалификаторы игнорируются).
Сделано было примерно для этого:
```c
typedef const int zip;
const zip q = 8;
```
