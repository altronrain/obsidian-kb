## Назначение квалификатора `volatile`

Данный квалификатор был введен для того, чтобы сообщать компилятору, что переменная или значения в ячейке памяти указателя *могут быть изменены действиями, внешними* по отношению к текущей выполняемой программе.

Например, программа ссылается на текущее показание системных часов, сама она его не меняет но оно изменяется с промежутками времени самой системой.

Пример:
```c
volatile int loc1;
volatile int *ploc;
```

## Причины добавления

Данное ключевое слово было введено в стандарте ANSI C для того чтобы у компилятора было представление о том, что изменяется с течением времени по независимым причинам, а что нет.

Если какой-то объект не меняется с течением времени и не содержит данного ключевого слова, то компилятор может оптимизировать работу с ним и поместить его в регистр (*закэшировать*), чтобы доступ к нему был быстрее.
Пример:
```c
val1 = x;
/* x не используется в некотором промежутке кода */
val2 = x;
```
В данном случае `x` может быть помещен в регистр.

## Совместное применение с квалификатором `const`

Возможно и совместное применение с квалификатором `const`. Тот же пример с системными часавми тут уместен.
* Сама программа не изменяет значения системных часов (`const`)
* Значение в данной ячейке меняется операционной системой с течением времени (`volatile`)

Пример:
```c
volatile const int loc;
const voilatile int *ploc;
```
