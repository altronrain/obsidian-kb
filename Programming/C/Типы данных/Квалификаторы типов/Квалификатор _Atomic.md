Параллельное программирование разделяет выполнение программы на потоки, которые выполняются параллельно. При этом возникают свои сложные задачи по организации работы. Одной из таких задач является управление потоками, манипулирующими одними и теми же данными.

В C11 представлены необязательные методы управления в виде заголовочных файлов `stdatomic.h` и `threads.h`.

Одной из концепций является *атомарный тип*. Пока поток выполняет *атомарную операцию* над объектом *атомарного типа*, гарантируется что *другие* потоки *не будут иметь доступа* к этому объекту.

Пример:
```c
/* обычные объявление и присваивание */
int hogs;
hogs = 12;

/* объявление объекта атомарного типа и присваивание ему значения */
_Atomic int hogs;
atomic_store(&hogs, 12);
```

Сохранение значения 12 в `hogs` -- атомарный процесс, в течение которого другие потоки не будут иметь доступ к переменной `hogs` (а значит не смогут ее изменить).
