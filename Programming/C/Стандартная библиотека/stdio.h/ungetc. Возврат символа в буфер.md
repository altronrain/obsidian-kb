Имеет прототип:
```c
int ungetc(int c, FILE *fp);
```

Данная функция заталкивает символ, указанный в `c` "обратно" в указанный входной поток `fp`.

Если посредством `ungetc` мы вернули символ в поток, то он будет считан следующим вызовом `getchar` или `fgetc`.

Пример применения: необходимо считать все символы до определенного, не включая его.
* считываем символы пока не встретим стоп-символ (в том числе и его)
* возвращаем символ-ограничитель в поток/буфер

Стандарт ANSI C (C90) *гарантирует только одно заталкивание за один раз*.
Если *реализация* позволяет затолкнуть несколько символов, то функции ввода прочитают их в порядке, *обратном* заталкиванию.

Еще раз про ограничения:
* вернуть можно только один символ
* это реально должен быть символ, только что прочитанный из этого же потока
в остальных случаях результат неопределен.

Функция полезна при *лексическом анализе*, хотя можно обойтись и без нее. В ситуациях, когда невозможно понять, не прочитав *очередной символ*, является ли он *частью лексемы* или нет. Например:
```
756+27
```
Понять, что число `756` кончилось, можно лишь прочитав `+`. Вероятнее всего обработка чисел реализована отдельной функцией, в которой не хочется описывать все разделители. В такой ситуации функция `ungetc` сэкономит много времени
