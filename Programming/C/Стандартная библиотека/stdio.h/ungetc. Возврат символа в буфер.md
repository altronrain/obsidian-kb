Имеет прототип:
```c
int ungetc(int c, FILE *fp);
```

Данная функция заталкивает символ, указанный в `c` "обратно" в указанный входной поток `fp`.

Если посредством `ungetc` мы вернули символ в поток, то он будет считан следующим вызовом `getchar` или `fgetc`.

Пример применения: необходимо считать все символы до определенного, не включая его.
* считываем символы пока не встретим стоп-символ (в том числе и его)
* возвращаем символ-ограничитель в поток/буфер

Стандарт ANSI C (C90) *гарантирует только одно заталкивание за один раз*.
Если *реализация* позволяет затолкнуть несколько символов, то функции ввода прочитают их в порядке, *обратном* заталкиванию.
