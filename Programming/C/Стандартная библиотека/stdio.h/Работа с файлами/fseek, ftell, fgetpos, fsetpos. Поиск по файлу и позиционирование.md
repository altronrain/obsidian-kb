Стандартная библиотека предоставляет возможность выполнять перемещение по содержимому файла (с точностью до байта). Данные функции, что логично, рекомендуется применять в двоичном режиме работы с файлами (см. [[Режимы работы с файлами#Режимы работы с файлами]] и [[fread, fwrite. Блочный ввод-вывод]])

Функции, выполняющие указанные действия, называются `fseek` и `ftell`
* `fseek` устанавливает позицию в файле
* `ftell` сообщает текущую позицию в файле

Функции, добавленные в ANSI C (C90):
* `fsetpos` устанавливает позицию в файле
* `fgetpos` сообщает текущую позицию  в файле

Собсивенно, они делают то же самое. Их ввели чтобы решить проблему ограничения размера файла (допустим в байтах) значениями типа `long`.

# Базовые функции
### Функция `fseek`

Имеет прототип:
```c
int fseek(FILE *stream, long offset, long start);
```
где:
* `FILE *stream` -- "указатель" на файл, предварительно открытый `fopen`
* `long offset` -- смещение относительно стартовой точки (3 аргумента)
	* может быть как положительным (вперед), так и отрицательным (назад)
* `long start` -- стартовая точка

Начиная с ANSI C (C90) в заголовочном файле `stdio.h` определены следующие стандартные стартовые точки:
* `SEEK_SET` -- от начала файла (эквивалент `0L`)
* `SEEK_CUR` -- от текущей позиции (эквивалент `1L`)
* `SEEK_END` -- от конца файла (эквивалент `2L`)

Функция возвращает `0` если  не возникло ошибок и `-1` в случае ошибки (например попытке выйти за пределы файла).

Не все потоки допускают изменение текущей позиции. Например, потоки, связанные с терминалом такой возможности не дают (как на ввод так и на вывод), ибо данные нигде не хранятся, так что понятие текущей позиции для них не существует.

### Функция `ftell`

Имеет прототип:
```c
long ftell(FILE *stream);
```
где:
* `FILE *stream` -- "указатель" на файл, предварительно открытый `fopen`(соответственно, чаще всего -- массив `char` статический или динамический)

Функция возвращает текущую позицию в файле. А именно: смещение относительно начала файла, где первый байт имеет номер `0`.

Стандарт ANSI C (C90) применяет такую нумерацию к файлам, открытым в *двоичном* режиме, но не обязательно к файлам в *текстовом* режиме.
В текстовом режиме стандарт утверждает, что `ftell` возвращает значение, которое может быть использовано в качестве второго аргумента `fseek`.
Так например в MS-DOS `ftell` может возврачать количество, при подсчете которого `\r\n` рассматривается как 1 байт.

## Ограничения переносимости для указанных функций

Функции `fseek` и `ftell` в идеале заточены под модель файлов Unix. Но разнообразие ОС привносит свои коррективы. Стандарт ANSI C предоставляет для данных функций *пониженные* ожидания, вводя ряд *ограничений*, касающихся переносимости:

* в *двоичном* режиме реализации *не обязаны поддерживать* `SEEK_END` (более переносимым но медленным подходом будет побайтовое чтение файла пока не встретится его конец)
* в *текстовом* режиме гарантируется работа только следующих вызовов `fseek`:
```c
fseek(file, 0L, SEEK_SET)        /* переход в начало файла */
fseek(file, 0L, SEEK_CUR)        /* остаться в текущей позиции */
fseek(file, 0L, SEEK_END)        /* перейти в конец файла */
fseek(file, ftell_pos, SEEK_SET) /* перейти в позицию ftell_pos от начала */
                                 /* ftell_pos от ftell в текстовом режиме */
```

# Функции из ANSI C (C90)

Вместо типа `long` оперируют искуственным типом `fpos_t` (file position type), который *не является базовым* типом и чья реализация *может отличаться* на различных платформах.

## Функция `fgetpos`

Имеет прототип:
```c
int fgetpos(FILE * restrict stream, fpos_t * restrict pos);
```

Вызов `fgetpos` помещает текущее значения типа `fpos_t` в ячейку, указанную `pos`. Полученное значение *описывает* текущую позицию в файле.

Функция возвращает `0` в случае успеха и *ненулевое* значение при отказе/ошибке.

## Функция `fsetpos`

Имеет прототип:
```c
int fsetpos(FILE * stream, const fpos_t *pos);
```

Вызов `fsetpos` использует значение из ячейки `pos` типа `fpos_t`, для установки указателя файла на позицию, которую *отражает/описывает* данное значение.

Функция возвращает `0` в случае успеха и *ненулевое* значение при отказе/ошибке.

Значение `fpos_t` должно быть получено вызовом `fgetpos`.

Не все потоки допускают изменение текущей позиции. Например, потоки, связанные с терминалом такой возможности не дают (как на ввод так и на вывод), ибо данные нигде не хранятся, так что понятие текущей позиции для них не существует.
