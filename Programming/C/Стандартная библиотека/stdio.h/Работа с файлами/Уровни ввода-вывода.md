## Разновидности уровней ввода-вывода

Помимо представления файла (двоичного или текстового, см. [[Режимы работы с файлами]]) в большинстве случаев можно выбрать один из *двух* уровней *ввода-вывода* (уровней управления доступом к файлам):

* *Низкоуровневый* ввод-вывод -- использование средств и служб, предоставляемых операционной системой)
* *Стандартный высокооуровневый* ввод-вывод -- применение *стандартного* пакета библиотечных функций C из заголовочного файла `stdio.h`

Стандарт, естественно, поддерживает только стандартный пакет ввода-вывода, так как нет никакой гарантии в одинаковой низкоуровневой модели среди зоопарка ОС. Имеет смысл рассмотреть только его (за остальным -- API ОС)

## Стандартный ввод-вывод

Преимущества стандартных высокоуровневых средств ввода-вывода над низкоуровневыми средствами, предоставляемыми ОС:

* Переносимость (уже отмечена ранее)
* Автоматическое преобразование форм данных в строковый вывод (например у `printf`)
* [[fflush, setvbuf. Буферизация ввода-вывода]] (передача информации крупными порциями, а не по байту за раз)
