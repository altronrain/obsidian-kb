## Функция `strchr`

Выполняет поиск первого вхождения указанного символа в строке. Имеет следующий прототип:
```c
char * strchr(const char *s, int c);
```

Функция ищет первое вхождение символа `c` в строке `s` и возвращает указатель на эту ячейку. Если символ в строке не найден -- возвращает нулевой указатель `NULL`

## Функция `strrchr`

Выполняет поиск последнего вхождения указанного символа в строке. Имеет следующий прототип:
```c
char * strrchr(const char *s, int c);
```

Функция ищет последнее вхождение символа `c` в строке `s` и возвращает указатель на эту ячейку. Если символ в строке не найден -- возвращает нулевой указатель `NULL`
