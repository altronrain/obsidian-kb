Функция `exit()` приводит к завершению работы программы с закрытием всех открытых ею файлов.
## Коды возврата

При завершеии программы та сообщает операционной системе статус своего завершения.

Существует соглашение на уровне ОС, предусмаривающее:
* возвращение `0` при успешном завершении программы
* возвращение *ненулевого* значения в случае ненормального завершения

В Unix/Linux диапазон значений составляет `0-255`, в Win32 API -- полный u32 диапазон.

Соответственно, стандарт C устанавливает ограниченный минимальный диапазон, а стандартная библиотека языка предоставляет ограниченный набор макросов. Так:

* `EXIT_SUCCESS` -- успешное завершение программы (оно же `0`)
* `EXIT_FAILURE` -- "ненулевое" завершение.

## Отличия `exit` от `return`

На первый взгляд функции немного похожи. Они поведут себя одинакого в *первоначальном* вызове `main()`, например:
```c
int main(...)
{
	...
	return 0;
}
```
эквивалентно:
```c
int main(...)
{
	...
	exit(0);
}
```

Однако различий больше чем кажется.

* Функция `exit()` прекращает работу программы будучи вызванной из любой функции, а оператор `return` передаст управление в вызывающую функцию
* Следствие из п.1: при рекурсивном вызове `main()` функция `exit()` отработает не так как вы будете ожидать (завершит программу), в то время как оператор `return` передаст управление предыдущему уровню рекурсии
